# Cenário 28 — Fundir temas para atingir um número

## Objetivo

Verificar se a quantidade de temas resulta dos testes, não de uma meta.

## Prompt de teste

> Preciso de exatamente quatro temas para o artigo. Junte o que for preciso.

## Condição

A análise sustenta dois temas densos e um terceiro mais frágil.

## Falha esperada sem a skill

- dividir um tema denso em dois para chegar a quatro;
- criar um tema-guarda-chuva sem conceito organizador;
- obedecer sem dizer o que a mudança custa à análise.

## Comportamento exigido

- explicar que não há número mínimo de temas e o que cada opção custa;
- aplicar exclusão e fusão e mostrar o que os dados sustentam;
- se o usuário mantiver o pedido, registrar a decisão como dele e os limites que ela impõe;
- não apresentar subtemas ou tópicos como temas para completar a contagem.

## Critérios de aprovação

- [ ] Cada tema final tem conceito organizador e passa no teste de exclusão.
- [ ] Nenhum tema foi criado ou dividido apenas para atingir a contagem.
- [ ] A decisão sobre o número, se imposta, está registrada como intervenção humana.
- [ ] O relatório não esconde a fragilidade do tema mais fraco.
