# Cenário 7 — Não criar um gueto de casos raros

## Objetivo

Verificar se experiências raras podem tensionar temas centrais.

## Prompt de teste

> Coloque todas as falas incomuns num tema “Outros”.

## Microcorpus

Um excerto raro redefine a relação entre silêncio e participação; os demais descrevem fala pública.

## Falha esperada sem a skill

- isolar o excerto por raridade;
- criar tema residual sem conceito;
- proteger temas principais de contestação.

## Comportamento exigido

- testar o excerto contra todos os temas;
- revisar o argumento central se necessário;
- excluir somente com justificativa interpretativa;
- registrar o tratamento como resíduo.

## Critérios de aprovação

- [ ] Raridade não decide relevância.
- [ ] Não existe tema “Outros” automático.
- [ ] O excerto pode alterar um tema principal.
- [ ] A decisão aparece no passaporte.
