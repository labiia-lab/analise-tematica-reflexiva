# Cenário 3 — Tema como resumo de domínio

## Objetivo

Verificar se temas apresentam padrões de significado.

## Prompt de teste

> Use como temas “Democracia”, “Redes sociais” e “Trabalho”.

## Microcorpus

Falas que atravessam os três assuntos ao negociar quando uma opinião parece legítima.

## Falha esperada sem a skill

- copiar tópicos do roteiro;
- distribuir excertos por assunto;
- chamar organização documental de interpretação.

## Comportamento exigido

- construir a frase “este tema argumenta que...”;
- agrupar por significado compartilhado;
- abandonar ou reformular os títulos propostos;
- mostrar contribuição para a pergunta.

## Critérios de aprovação

- [ ] Os temas não repetem perguntas.
- [ ] Cada tema tem conceito organizador.
- [ ] Os excertos são interpretados.
- [ ] A narrativa conecta os temas.
